1 · Fusion Audio↔Visual — ¿Por que esta asignacion?

score(speaker_audio, persona_visual) =
  suma_segmentos [ frac_frames_LAR_activa x (1 + intensidad_LAR) x duracion ]
  / duracion_total_speaker

frac_frames_LAR_activa: % de frames donde LAR > umbral adaptativo de esa persona.
intensidad_LAR_activa: valor medio del LAR en frames activos (mayor apertura = mayor peso).
Asignacion greedy: se elige el par con mayor score, luego el segundo, etc.

2 · Evidencia LAR — ¿Cuando esta seguro el sistema?

umbral_adaptativo(persona) = max(0.05, percentil_70(LAR_persona) x 0.4

Cada persona tiene un umbral calibrado a su rango natural de movimiento labial.
Umbral alto → esa persona mueve mucho los labios (necesita mas apertura para detectarla).
Umbral bajo → esa persona tiene movimientos mas sutiles.

Zonas de confianza en la senal LAR

Verde: LAR > 120% umbral → alta confianza habla.
Naranja: LAR entre 80% y 120% umbral → borderline.
El % en cada segmento SRT = fraccion de frames en zona verde.

LAR = gap_vertical(LIP_TOP, LIP_BOTTOM) / gap_horizontal(LIP_LEFT, LIP_RIGHT)

dLAR/d(gap_vertical) = +1/h → abrir la boca sube LAR (detecta habla)
dLAR/d(gap_horizontal) = -v/h2 → ensanchar baja LAR

3 · Espacio de Embeddings — ¿Como distingue las identidades?

Modelo: ArcFace via DeepFace (512 dimensiones)

ArcFace proyecta cada cara a un vector de 512 dims entrenado para maximizar la separacion entre identidades.
El t-SNE reduce esas 512 dims a 2D; los clusters deben corresponder con las personas.
El heatmap de similitud coseno muestra que tan bien el sistema separa las identidades.

Re-ID: si similitud_coseno(embedding_nuevo, embedding_banco) ≥ 0.65 → misma persona
